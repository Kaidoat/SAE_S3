Mentions légales

Projet réalisé dans le cadre d’une formation universitaire

Ce site web a été conçu dans le cadre d’un projet pédagogique de deuxième année de BUT Informatique à l’Université Paris Cité (promotion 2026). Il s’agit d’un travail universitaire fictif visant à illustrer les compétences en développement web, gestion de projet et conception d’applications. Le site ne représente pas un site officiel de l’association Les Blouses Roses.

Responsabilité :
Le contenu de ce site est entièrement fictif. Il n’a pas vocation à être utilisé dans un cadre professionnel, commercial ou associatif réel. Les textes, images et informations affichées ont pour seul but de démontrer les compétences acquises durant la formation.

Hébergement :
Projet hébergé à titre d’exercice pédagogique sur un espace universitaire ou une plateforme d’hébergement temporaire (ex. GitHub Pages, Netlify, ou serveur de l’IUT). Aucune donnée personnelle réelle n’est collectée.

Protection des données :
Aucune donnée personnelle réelle n’est enregistrée ni exploitée. Les formulaires de connexion, de messagerie ou de compte donateur sont purement démonstratifs. En cas de test de la plateforme, aucune information saisie n’est conservée.
